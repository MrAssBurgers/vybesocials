# Website support and profile clip viewer

## Repairs

- About and Contact previously sent their Sign In link to the anonymous marketing homepage. Both now open `/login`, expose the current page in public navigation and have 44px-high header controls. Contact links directly to the complete FAQ, feature availability and authenticated deletion-request controls.
- Contact advertised subscriptions, cash creator monetization, guaranteed moderation response times and message encryption inconsistent with the current app. Support answers now describe the existing free core, unavailable paid/cash features, DM privacy limits and the existing deletion-request review process. FAQ deletion text and its FAQPage metadata use the same current request contract. This does not implement permanent deletion or change formal legal policies.
- Live profile clips rendered a fixed player inside a transformed profile scroller. The observed video rectangle started at y=-210 and the close control was offscreen; Escape did not close it. The viewer now portals to the document through the existing Radix dependency, traps focus, supports Escape and returns focus to the original clip. Named thumbnail buttons and previous/next controls support keyboard use. Radix owns scroll-lock cleanup on close/unmount. Clip identity survives list reordering; removed clips close rather than selecting another post. Each selected ShortCard starts with its own component state. Profile content selectors expose their pressed state and have 44px-high targets.
