# Firebase token recovery — October 6, 2026

The compatibility Auth adapter listened to onAuthStateChanged, which reports account changes rather than subsequent token refreshes. Its TOKEN_REFRESHED event came only from enrichment during an account event. If initial enrichment failed due to networking, later Firebase token recovery was invisible to AuthProvider's existing transient-profile-bootstrap retry path. Subscribe to onIdTokenChanged instead; emit initial/account events for their actual transitions and only TOKEN_REFRESHED for the same SDK user. Existing event generation, SDK object, auth intent, unsubscribe and durable logout guards remain intact. No Auth configuration, credentials, storage purge, provider permission or location consent change.
