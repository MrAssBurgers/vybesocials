## Safety panel loading and retirement repair

The panel now renders a retry state for failed settings reads and waits for a loaded, matching Auth/profile before edits. Adult-only filter availability is scoped to Auth epoch, profile and a local profile-visit generation. Changing profiles, including A-to-B-to-A without an Auth epoch change, immediately denies old age proof and draft reuse while a new read is pending. The sensitive-profile response must identify the current profile; rejected, absent or mismatched responses cannot enable the adult option. Unmounted/retired reads and save callbacks are ignored.

Keyword drafts clear only after a successful current-account save, remain editable for retry after failure, and do not disappear because an old account's save completes. Pending saves disable the controls and a synchronous scope guard prevents overlapping saves. Duplicate submitted keywords are collapsed. Add/remove keyword controls have accessible names. This restores reliability of existing controls; it does not add features or establish server age/PIN enforcement.
